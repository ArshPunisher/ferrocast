# Testing

How each kind of test runs here. `tools/check.sh` runs every gate in CI's order (rustfmt,
clippy with `-D warnings`, the tests with nextest, cargo deny, shellcheck).

| Kind | What it covers | Run |
|---|---|---|
| **Unit** | Pure logic in `core`: alert rules, templates (`render_parts` highlight runs, plurals), and designs (`core::design`, `core::layer`): JSON shape, look picking and fallbacks (resub → sub, Super Chat → tip…), variation priority, rendering onto an alert with viewer text kept as text, the TTS switch and minimum (paid amounts only), the branding rule (copies are never built-in, branded or Pro; mark layers stripped), every field check with a message that names it, CSS that tries to load files (escapes and comments decoded first), layer and widget-style checks. | `cargo test -p ferrocast-core` |
| **Store** | The `designs` repository (insert, list, update keeps id/origin/created_at, kind can't change, Pro never sticks), the active alert design, migration 0009 from a version 8 database (backup taken, overlays kept), `.ferropack` carrying designs and never forged built-ins, `.ferrodesign` export and import (round trip with media, a theme bringing its alert design, hostile files: not a zip, no manifest, scripts or pages inside, wrong checksums, pages dressed as pictures, newer versions, invalid designs, duplicate ids, oversized files). | `cargo test -p ferrocast-store` |
| **Engine** | The catalogue (only valid `builtin.*` designs load), created designs are always the streamer's own, duplicating a built-in theme copies its alert design without the mark, the active design dresses real and test alerts (designer test with a design and an amount), TTS on top of the policy, Use for themes (one overlay per scene, URL kept on an existing overlay), widget designs, the branding check on overlay edits, `?test` previews, design files through the engine, reload keeps the active design. | `cargo test -p ferrocast-engine designs` |
| **Integration** (server over a real socket) | Every `/api/v1/designs` route and every way it's refused, with our error shape: 401, 400 (bad JSON, wrong field type, a field that fails a check, bad kind), 404, 409 (`built_in`, `in_use`, `branding`, kind change), 413 (JSON over 1 MB, design file over 100 MB), 415 (not JSON, not multipart, `bad_design_file`, `unsafe_design_file`, `damaged_design_file`), 422 (`design_too_new`, `invalid_design`), plus `POST /test` with `design_id` and `amount`, and media a design uses refusing deletion. | `cargo test -p ferrocast-server designs_tests` |
| **Regression** | The whole workspace. | `cargo test --workspace` (or `tools/check.sh`) |
| **Smoke** | The quick path: core and store design tests plus the server design routes. | `cargo test -p ferrocast-core design && cargo test -p ferrocast-server designs_tests` |
| **Sanity** | Formatting and lints. | `cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings` |

Notes

- Fixtures for designs live in `crates/core/fixtures/designs/` and are shared by the store,
  engine and server tests.
- Server tests load a fixed catalogue (`parse_catalog`), never whatever web build sits next to
  the repo, and never touch OBS: the engine's OBS detection paths are empty in tests.
- Tests use temporary data folders and in-memory secrets; nothing reads the developer's real
  data, keychain or OBS settings.

## Studio (streamer tools)

Counters, quotes, chat modules, the stream-info editor, Start/End show, OBS helpers and moments. Nothing in these tests can reach a real OBS: the engine is always pointed at the fake OBS (`ferrocast-testkit::obs`, an obs-websocket v5 server on a random port with scenes, sources, inputs, the replay buffer, GetStats and the stream output) or at a port nothing listens on.

**Core unit** (`crates/core/src/{chatbot,stream_info,show,moments}.rs`): counter names and every `!deaths` form (`+`, `+5`, `+ 5`, `add 5`, `-`, `set 10`, `=10`, `reset`, junk, huge numbers), clamping at ±1e9, `{count:name}` in templates (and `{name:x}` still refused); quote parsing (add keeps spacing, strips control characters, 400-char cap, `#12`, remove) and dates; module settings and their limits; 8ball, dice (`NdM` limits), bets (`all`, `half`, `10%`, too small/big, not enough), roulette odds never 0 % or 100 %; long durations; duel challenges (one each, expiry, per platform); stream-info validation (title 140 characters not bytes, tags in any script, duplicates, 10 max, language codes, clearing tags), presets (unique names, renaming itself), history (20, newest first); show config and scene names, the disk check, `!scene` allow-list with prefixes; OBS health from two readings (dropped, encoder, render, CPU, disk, reconnecting; counters that reset never give negative or huge numbers); moments thresholds (settled tips only, other currencies, Shared Chat ignored, tests ignored), the chat-spike meter (one marker per spike, history needed, out-of-order times), CSV/TXT exports (formula injection defused, one line per marker).

**Adapter tests against fake platform APIs**: Twitch (`testkit::twitch`: Modify Channel Information with the game looked up by exact name, a picked id, an unknown name, a refused title, category search, stream markers, follow dates; a sign-in without `channel:manage:broadcast` is refused before calling Twitch, and Twitch's own 401 "Missing scope" becomes `MissingScope`, not "sign in again"); Kick (PATCH `/public/v1/channels` shape, category lookup, no language, a 403 becomes "reconnect for `channel:write`"); YouTube (the live or next scheduled broadcast's video, description kept, read-only fields dropped, 100-character titles, no broadcast is a clear refusal); OBS control (`crates/obs/src/control.rs`: scenes top-first, switching, an unknown scene's message, visibility, mutes, replay buffer not running / switched off / already running, GetStats + stream status).

**Store** (`repo/studio.rs`): counters in one write, quotes list/edit, markers with their stream offset (labels cleaned and capped), watch time, and a version-9 database migrating with its counters and quotes kept.

**Engine integration** (`crates/engine/src/studio/tests.rs`, chat through the real pipeline, replies recorded by a fake platform): counters for viewers vs mods, clashes with custom and built-in commands, `{count:deaths}` in a custom command, overlay label frames; quotes from chat (viewers can't add, and that doesn't use up their cooldown) and the dashboard; modules (8ball, roll, uptime, followage, shoutout, cooldowns, switched off, a custom `!uptime` wins, bad settings name the field); roulette and duels move points but never make them; watch time only while live; stream info partial success (a platform missing its scope says reconnect, Kick skips language), only some platforms, a platform not connected, nothing connected (422); presets and the reconnect hints from saved scopes; Start show with a muted mic failing pre-flight, the one-click unmute, every step's result, alerts resumed, replay buffer started, countdown → live scene by itself and by skip, one show at a time, End show (ending scene and thank-you); OBS closed (pre-flight fails with the fix link, steps fail with OBS's message); scenes, sources, BRB with mute and return, `!scene` allow-list, viewers ignored, `!brb`/`!back`; clip that (not running, saved with a clip marker, `!clip` and its cooldown); health warnings and the watcher's frames; BRB during a Twitch ad; big tips, first chatters, dismissals, tests never pinned; exports; a chat spike while live.

**Routes** (`crates/server/src/routes/studio/tests.rs`, real socket): 401 for every Studio route without the session; counters 201/400/404/409/415; quotes and modules; stream info 200 / 207 / 422 (with each platform's result in the body), categories 400/422, presets 201/400/404/409; show with OBS closed (422 `preflight_failed`, `obs_unreachable`) and open (201, 409, cancel, live scene, end); OBS helpers (422 `obs_unreachable`, `obs_refused`, `no_brb_scene`, replay not running with a hint, 400 for bad bodies); moments (lane dismiss 404, markers 201/400/404, CSV and TXT downloads with headers, bad `since` and `format`). Smoke (`smoke_every_studio_screen_loads`): every Studio GET a screen needs answers 200 with JSON.

**Dashboard** (`ferrocast-web/apps/dashboard/e2e/studio.spec.ts`, demo engine): see that repo's TESTING.md.
