# Fonts

Latin, variable-weight WOFF2 files from Fontsource 5.3.0, built into the setup program:

- `bricolage.woff2`: Bricolage Grotesque, Copyright 2022 The Bricolage Grotesque Project Authors.
- `hanken.woff2`: Hanken Grotesk, Copyright 2021 The Hanken Grotesk Project Authors.
- `jetbrains-mono.woff2`: JetBrains Mono, Copyright 2020 The JetBrains Mono Project Authors.
